# Orpheon

Two data scientists doing the work nobody has budget for.

## Local preview

```bash
python3 -m http.server 8080
```

Visit `http://localhost:8080`.

## GitHub Pages

1. **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main`, folder: `/ (root)`
4. Site URL: `https://<username>.github.io/orpheus/`

## Customize

- Contact email: `hello@orpheon.dev` in `index.html` / `main.js`
- Live stats & chart: `index.html` + `main.js`
- Colors: CSS variables in `styles.css`
